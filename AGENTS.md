# Project guidance

Read `design/DESIGN.md` before changing the interface. It records Phoniex's cross-project design preference and the selected TermQuill direction. Keep related pages visually consistent, preserve responsive behavior and accessibility, and verify the complete user task.

Run `npm test`, `npm run check` and `npm run build` for application changes. The build generates browser copies of shared modules and route HTML; edit their source templates and `lib` originals rather than generated files.
