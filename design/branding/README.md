# TermQuill identity

October 29, 2026: original open-book and quill mark. The book represents supplied teaching material; its rising quill represents shaping that material into an editable assessment. The small violet tip connects to the editing tools.

Production master: `public/favicon.svg`. Navy #202D49, cobalt #4164DD, paper #F6F8FF and violet #A98BFA. The simple vector geometry stays sharp in the application header and browser tab. Retain generous internal padding and do not stretch the mark. Existing TermQuill text supplies the accessible brand name; header images remain decorative.

The initial concept was created with the built-in image generation tool and adapted into an original compact SVG for production. `termquill-logo-concept.png` is the local design reference, not a runtime dependency.

Concept prompt: “An exquisite original app logo symbol for TermQuill, an educational lesson and assessment authoring platform. Symbol only. An open book / turning folded page whose right side becomes an elegant upward quill, with a subtle T in the negative space. Strong silhouette, architectural precision, balanced curves. Deep midnight navy, saturated cobalt and a restrained violet detail. Navy rounded-square app tile, transparent outside. Crisp edges, generous padding, recognizable as a browser favicon. No graduation caps, book text or watermark.”
