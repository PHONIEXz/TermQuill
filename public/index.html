FROM NOTES TO PAPER

A small tool for a busy teacher.

1. Paste your lesson notes and choose your assessment settings.

2. Gemma drafts questions with verbatim supporting quotes. The app checks counts, formats, answer fields and marks, then retries once if needed.

3. Edit and review each question. Confirm the review, then print the student paper and marking guide separately.

The sample is hand-authored, not a live AI response. Hosted generation needs the owner’s server-side API configuration. No payments or subscriptions are collected in this pilot.

Notes are sent to Google when you generate. Device saving is optional and uses this browser’s local storage. Clearing a saved draft does not delete a JSON file you downloaded.
